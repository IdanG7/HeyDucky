## [0.1.0] - 2026-02-24

### Added
- Voice-controlled AI debugging assistant with Textual TUI
- Push-to-talk voice input via local Whisper speech-to-text
- Claude AI integration for code analysis and debugging conversations
- DAP (Debug Adapter Protocol) client supporting Python, C/C++, Go, and Rust
- Chat mode for rubber-duck conversations about your code
- Debug mode for stepping through local scripts hands-free
- Remote debug mode for attaching to remote debugpy sessions
- Text-to-speech responses via ElevenLabs (the duck talks back!)
- Interactive setup wizard (`ducky --setup`)
- Configurable via `~/.config/ducky/config.toml`
- Keyboard shortcuts for full hands-free workflow
- Homebrew formula and macOS installer script
- Remote debugging agent with GUI and headless modes
